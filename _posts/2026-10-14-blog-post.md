We use the circle method to count solutions to linear Diophantine equations.

This post is dedicated to my girlfriend, who suggested I study the circle method. The exposition is loosely based on [A'Campo's undergraduate thesis](https://drive.google.com/file/d/1qcn-pm2foqslRsgiUujChqewR8BJ6nkB/view).

The Statement
-

Throughout, we fix a sequence \\((a\_1,\ldots,a\_s)\\) of positive integers, and we will be interested in the solutions to the equation
\\[a\_1x\_1+\cdots+a\_sx\_s=N,\\]
where \\(N\\) is a fixed positive integer. To avoid a distracting discussion of divisibility, we assume \\(\gcd(a\_1,\ldots,a\_s)=1\\) throughout.
<!-- For convenience, we define \\(A:=\operatorname{lcm}(a\_1,\ldots,a\_s)\\), but we will not use this until later. Here is our target. -->

> <span class="statement-label" id="def-desired" data-env="Definition">Definition.</span>
For a positive integer sequence \\((a\_1,\ldots,a\_s)\\) and a positive integer \\(N\\), define
\\[R\_a(N):=\\#\left\\{(x\_1,\ldots,x\_s)\in\mathbb Z\_{\ge0}^s:a\_1x\_1+\cdots+a\_sx\_s=N\right\\}.\\]

> <span class="statement-label" id="thm-linear" data-env="Theorem">Theorem.</span>
Let \\((a\_1,\ldots,a\_s)\\) be a sequence of positive integers for which \\(\gcd(a\_1,\ldots,a\_s)=1\\). Then for positive integers \\(N\\), we have
\\[R\_a(N)\sim\frac{N^{s-1}}{(s-1)!a\_1\cdots a\_s}\\]
as \\(N\to\infty\\).

It is tricky (but possible) to prove <a class="statement-ref" href="#thm-linear">Theorem</a> by a direct combinatorial argument; for example, this has been done by [Cimpoeas and Nicolae](https://arxiv.org/abs/1609.06090). We will provide two proofs using complex analysis (<a class="statement-ref" href="#thm-linear-genfunc">Theorem</a> and <a class="statement-ref" href="#thm-linear-circle">Theorem</a>). For context (and later use), here are some quickly achievable special cases.

> <span class="statement-label" id="ex-one" data-env="Example">Example.</span>
When \\(s=1\\), we have the positive integer sequence \\((1)\\). Then <a class="statement-ref" href="#thm-linear">Theorem</a> asserts that \\(R\_{(1)}(N)\sim1\\). Of course, \\(R\_{(1)}(N)=1\\) in this case.

> <span class="statement-label" id="ex-two" data-env="Example">Example.</span>
When \\(s=2\\), we have a positive integer sequence \\((a,b)\\) where \\(\gcd(a,b)=1\\), and <a class="statement-ref" href="#thm-linear">Theorem</a> asserts that \\(R\_{(a,b)}(N)\sim\frac1{ab}\cdot N\\). Let's show this directly: given \\(ax+by=N\\), we see \\(by\equiv N\pmod a\\), so \\(y\pmod a\\) is uniquely determined to be equivalent to some \\(r\_{a,b}(N)\in\\{0,1,\ldots,a-1\\}\\). Now, for each \\(y\in[0,N/b]\\) satisfying \\(y\equiv r\_{a,b}(N)\pmod a\\), there is a unique \\(x\\) for which \\(ax+by=N\\). Thus, \\(R\_{(a,b)}(N)\\) equals
\\[1+\left\lfloor\frac{\lfloor N/b\rfloor-r\_{a,b}(N)}{a}\right\rfloor=\frac N{ab}+O(1).\\]

> <span class="statement-label" id="ex-all-ones" data-env="Example">Example.</span>
When \\(a\_1=\cdots=a\_s=1\\), <a class="statement-ref" href="#thm-linear">Theorem</a> asserts \\(R\_a(N)\sim\frac1{(s-1)!}\cdot N^{s-1}\\). Let's show this directly: in fact, we claim \\(R\_a(N)=\binom{N+s-1}{s-1}\\). Indeed, lay down \\(N+s-1\\) blanks and place down \\(s-1\\) bars in the blanks; also place a bar before and after all the blanks. The distances between the bars gives a sequence \\((x\_1,\ldots,x\_s)\\) satisfying \\(x\_1+\cdots+x\_s=N\\), and such sequences are in bijection with bar arrangements.

> <span class="statement-label" id="rem-cor" data-env="Remark">Remark.</span>
<a class="statement-ref" href="#thm-linear">Theorem</a> implies that any sufficiently large positive integer \\(N\\) is a nonnegative integer linear combination of the \\(a\_\bullet\\)s. Taking differences, we find \\(a\_1\mathbb Z+\cdots+a\_s\mathbb Z=\mathbb Z\\). Let's show this last claim directly: let \\(g\\) be the smallest positive integer in \\(a\_1\mathbb Z+\cdots+a\_s\mathbb Z\\), and it is enough (by taking multiples) to show \\(g=1\\). Because \\(\gcd(a\_1,\ldots,a\_s)=1\\), it is enough to show \\(g\mid a\_k\\) for each \\(k\\). Well, note \\(a\_k-mg\in a\_1\mathbb Z+\cdots+a\_k\mathbb Z\\) for any \\(m\\). For a carefully chosen \\(m\\), one can achieve \\(a\_k-mg\in[0,g-1]\\), so \\(a\_k-mg=0\\) by minimality of \\(g\\), so \\(g\mid a\_k\\).

> <span class="statement-label" id="rem-frobenius-coin" data-env="Remark">Remark.</span>
When \\(a\_k\ge2\\) for each \\(k\\), it is an interesting problem to compute the largest positive integer which is not a nonnegative integer linear combination of the \\(a\_\bullet\\)s, even when \\(s=3\\).

Before continuing with the post, let's set some notation.
- Fix a sequence \\(a=(a\_1,\ldots,a\_s)\\) of positive integers for which \\(\gcd(a\_1,\ldots,a\_s)=1\\). Also define \\(A:=\operatorname{lcm}(a\_1,\ldots,a\_s)\\).
- The number \\(N\\) is always a (large) positive integer.
- Define \\(R\_a(N)\\) to be the number of nonnegative integral solutions to \\(a\_1x\_1+\cdots+a\_sx\_s=N\\).
- Define the generating function \\(f(z):=1/(1-z)\\) and its truncation \\(f\_N(z):=\left(1-z^{2N}\right)/(1-z)\\).
- Define the generating function \\(f\_a(z):=\prod\_kf(z^{a\_k})\\) and its truncation \\(f\_{a,N}(z):=\prod\_kf\_{N}(z^{a\_k})\\).
- Define \\(e\colon\mathbb C\to\mathbb C\\) by \\(e(z):=\exp(2\pi iz)\\).
- For \\(x\in\mathbb R\\), let \\(\lVert x\rVert\\) denote the distance between \\(x\\) and the nearest integer.
- The number \\(\varepsilon\\) is a real number in \\((0,1/2A)\\).
- The major arc is \\(\mathfrak M\_\varepsilon:=[-\varepsilon,\varepsilon]\\). The minor arc is \\(\mathfrak m\_\varepsilon:=[-1/2,1/2]\setminus\mathfrak M\_\varepsilon\\).
- For \\(b\in\mathbb Z/A\mathbb Z\\), define \\(\mathfrak m\_{b,\varepsilon}:=(b/A+\mathfrak M\_\varepsilon)\cap[-1/2,1/2]\\). Then define \\(\mathfrak m'\_{\varepsilon}:=\mathfrak m\_\varepsilon\setminus\bigcup\_b\mathfrak m\_{b,\varepsilon}\\).

Generating Functions
-

To crystallize some of the ideas, we prove <a class="statement-ref" href="#thm-linear">Theorem</a> in a way which circumvents some of the technicalities of the circle method. This argument is taken from Wilf's [generatingfunctionology](https://www2.math.upenn.edu/~wilf/gfology2.pdf).

Complex analysis enters analytic number theory via generating functions. In short, a generating function is a usually well-behaved (e.g., meromorphic) function whose coefficients encode interesting (e.g., arithmetic) information. Here is the function relevant to our story.

> <span class="statement-label" id="def-gen-func" data-env="Definition">Definition.</span>
Define \\(f(z):=1/(1-z)\\). For a positive integer sequence \\((a\_1,\ldots,a\_s)\\), define
\\[f\_a(z):=\prod\_{k=1}^sf\left(z^{a\_k}\right).\\]

> <span class="statement-label" id="lem-gen-func" data-env="Lemma">Lemma.</span>
For a positive integer sequence \\((a\_1,\ldots,a\_s)\\), we have
\\[f\_a(z)=\sum\_{N=0}^\infty R\_a(N)z^N.\\]
This is an equality of holomorphic functions on the open disk \\(\left\|z\right\|<1\\).

*Proof.*
This follows by directly expanding
\\[f\_a(z)=\Bigg(\sum_{x\_1=0}^\infty z^{a\_1x\_1}\Bigg)\cdots\Bigg(\sum_{x\_s=0}^\infty z^{a\_sx\_s}\Bigg)\\]
via the geometric series. (The geometric series converge absolutely when \\(\left\|z\right\|<1\\).) The direct expansion (e.g., as a Cauchy product) continues to converge absolutely, so we may rearrange to prove the lemma. \\(\blacksquare\\)

Thus, we are interested in the coefficients of the power series \\(f\_a(z)\\). Roughly speaking, the growth rate of the coefficients is controlled by pole behavior.

> <span class="statement-label" id="ex-basic-pole" data-env="Example">Example.</span>
By combining <a class="statement-ref" href="#ex-all-ones">Example</a> with <a class="statement-ref" href="#lem-gen-func">Lemma</a>, we see that
\\[\frac1{(1-z)^s}=\sum\_{N=0}^\infty\binom{N+s-1}{s-1}z^N,\\]
and \\(\binom{N+s-1}{s-1}\sim\frac1{(s-1)!}\cdot N^{s-1}\\). More generally, if \\(\alpha\\) has \\(\left\|\alpha\right\|=1\\), then the power series expansion
\\[\frac1{(1-\alpha z)^s}=\sum\_{N=0}^\infty\binom{N+s-1}{s-1}\alpha^Nz^N\\]
has coefficients which are \\(O(N^{s-1})\\).

We are thus motivated to understand something about the poles of the rational function \\(f\_a(z)\\). This will be done using a partial fraction decomposition.

> <span class="statement-label" id="lem-partial-fractions" data-env="Lemma">Lemma.</span>
Let \\(a(X)/q(X)\\) be a rational function in \\(\mathbb C(X)\\). Suppose we may factor \\(q(X)\\) as \\(\prod\_k(1-X/\alpha\_k)^{n\_k}\\) where the \\(\alpha\_\bullet\\)s are distinct and nonzero. Then there is a decomposition
\\[\frac{a(X)}{q(X)}=a\_0(X)+\sum\_k\Bigg(\sum_{n=1}^{n\_k}\frac{c\_{\alpha\_k,n}}{(1-X/\alpha\_k)^{n}}\Bigg),\\]
where \\(a\_0(X)\\) is a polynomial, and the \\(c\_{\alpha\_k,n}\\)s are constants.

*Proof.*
Let's start by reducing to the case where \\(q(X)\\) has only one root. Namely, if \\(q\_1(X)\\) and \\(q\_2(X)\\) are coprime polynomials in \\(\mathbb C[X]\\), then any polynomial \\(a(X)\\) admits a decomposition
\\[\frac{a(X)}{q\_1(X)q\_2(X)}=\frac{a\_1(X)}{q\_1(X)}+\frac{a\_2(X)}{q\_2(X)}\\]
for some polynomials \\(a\_1(X)\\) and \\(a\_2(X)\\). Indeed, upon clearing fractions, this amounts to solving \\(a(X)=a\_1(X)q\_2(X)+a\_2(X)q\_1(X)\\), which is possible because \\(q\_1(X)\mathbb C[X]+q\_2(X)\mathbb C[X]=\mathbb C[X]\\). For example, one should use that \\(\mathbb C[X]\\) is a principal ideal domain here.

Thus, the factorization of \\(q(X)\\) allows us to assume that \\(q(X)\\) has the form \\((1-X/\alpha)^n\\). By rescaling \\(X\\), we may assume that \\(q(X)=(1+X)^n\\). By shifting \\(X\\), we may assume that \\(q(X)=X^n\\). Then we may write
\\[\frac{a(X)}{X^n}=a\_n(X)+\sum\_{k=0}^{n-1}\frac{a\_k}{X^{n-k}},\\]
where \\(a\_n(X)\\) is a polynomial and \\(a\_kX^k\\) is a monomial in \\(a(X)\\). \\(\blacksquare\\)

We are now ready to prove <a class="statement-ref" href="#thm-linear">Theorem</a> with an explicit error term.

> <span class="statement-label" id="thm-linear-genfunc" data-env="Theorem">Theorem.</span>
Let \\((a\_1,\ldots,a\_s)\\) be a sequence of positive integers for which \\(\gcd(a\_1,\ldots,a\_s)=1\\). Then for positive integers \\(N\\), we have
\\[R\_a(N)=\frac{N^{s-1}}{(s-1)!a\_1\cdots a\_s}+O\_a\left(N^{s-2}\right).\\]

*Proof.*
By <a class="statement-ref" href="#lem-gen-func">Lemma</a>, we are interested in the growth rate of the coefficients of the power series of \\(f\_a(z)\\). By <a class="statement-ref" href="#lem-partial-fractions">Lemma</a>, \\(f\_a(z)\\) can be written as
\\[f\_a(z)=p(z)+\sum\_\alpha\Bigg(\sum\_{n=1}^{\operatorname{ord}\_\alpha(f\_a)}\frac{c\_{\alpha,n}}{(1-z/\alpha)^n}\Bigg),\\]
where \\(p(z)\\) is some polynomial, the \\(\alpha\\)s vary over the poles of \\(f\_a\\) (where \\(\operatorname{ord}\_\alpha(f\_a)\\) is the order of the pole), and the \\(c\_{\alpha,n}\\)s are some coefficients. (Note zero is not a pole.) Here are some remarks on these poles.
- All poles occur at roots of unity. Indeed, the poles of \\(f\_a(z)\\) correspond to roots of \\(1-z^{a\_k}\\) as \\(k\\) varies.
- There is a pole at \\(\alpha=1\\) of order \\(s\\). Indeed, for each \\(k\\), we see \\(1-z^{a\_k}\\) has a zero at \\(z=1\\) of order one.
- All other poles \\(\alpha\\) have smaller order. Indeed, for each \\(k\\), each root of \\(1-z^{a\_k}\\) occurs with multiplicity one, so the total multiplicity is at most \\(s\\). Furthermore, equality holds only if \\(\alpha\\) is a root of \\(1-z^{a\_k}\\) for each \\(k\\), and then \\(\alpha^{a\_k}=1\\) for each \\(k\\). By taking linear combinations of the \\(a\_k\\)s, we find that \\(\alpha=1\\). (See <a class="statement-ref" href="#rem-cor">Example</a>. Only here we use \\(\gcd(a\_1,\ldots,a\_s)=1\\).)

We now plug in our partial fraction decomposition into <a class="statement-ref" href="#ex-basic-pole">Example</a>: the pole of order \\(s\\) at \\(1\\) contributes a main term of \\(\frac{c\_{1,s}}{(s-1)!}\cdot N^{s-1}\\), and all other poles contribute error terms of order \\(O\_a\left(N^{s-2}\right)\\). Thus, by <a class="statement-ref" href="#lem-gen-func">Lemma</a>,
\\[R\_a(N)=\frac{c\_{1,s}N^{s-1}}{(s-1)!}+O\_a\left(N^{s-2}\right).\\]
It remains to compute the constant \\(c\_{1,s}\\). By construction, \\(c\_{1,s}\\) is the limit of \\((1-z)^sf\_a(z)\\) as \\(z\to1\\). This limit expands out as a product of the limits
\\[\left(\lim_{z\to1}\frac{1-z^{a\_k}}{1-z}\right)^{-1}=a\_k^{-1}\\]
as \\(k\\) varies. Thus, \\(c\_{1,s}=1/(a\_1\cdots a\_s)\\), and the theorem follows. \\(\blacksquare\\)

> <span class="statement-label" id="rem-poly" data-env="Remark">Remark.</span>
A careful examination of the proof shows that the restriction of \\(R\_a(N)\\) to any residue class in \\(\mathbb Z/A\mathbb Z\\) is a polynomial. (Recall \\(A=\operatorname{lcm}(a\_1,\ldots,a\_s)\\).) Indeed, this follows once we expand out the contributions of the error terms from the partial fraction decomposition; the point is that \\(f\_a(z)\\) has all its poles located at \\(A\\)th roots of unity.

The Circle Method
-

We now introduce the circle method. The idea is to use Cauchy's integral formula to compute the coefficients of the power series \\(f\_a(z)\\). Indeed, by <a class="statement-ref" href="#lem-gen-func">Lemma</a>, we see that
\\[R\_a(N)=\frac1{2\pi i}\oint\_\gamma\frac{f\_a(z)}{z^{N+1}}\,dz,\\]
where \\(\gamma\\) is a small counterclockwise loop around \\(0\\). It will be convenient to integrate over \\(\\{z\in\mathbb C:\left\|z\right\|=1\\}\\), so we truncate \\(f\_a(z)\\) to make it entire.

> <span class="statement-label" id="def-truncated-gen-func" data-env="Definition">Definition.</span>
Define \\(f\_N(z):=\left(1-z^{2N}\right)/(1-z)\\). For a positive integer sequence \\((a\_1,\ldots,a\_s)\\), define
\\[f\_{a,N}(z):=\prod\_{k=1}^sf\_N\left(z^{a\_k}\right).\\]

One could truncate differently; for example, one could take the product over \\(f\_{AN/a\_k}(z^{a\_k})\\). This choice will not matter very much.

> <span class="statement-label" id="lem-truncated-gen-func" data-env="Lemma">Lemma.</span>
For a positive integer sequence \\((a\_1,\ldots,a\_s)\\) and positive integer \\(N\\),
\\[R\_a(N)=\int\_{\mathbb R/\mathbb Z}f\_{a,N}(e(x))e(-Nx)\,dx.\\]

*Proof.*
Exactly as in <a class="statement-ref" href="#lem-gen-func">Lemma</a>, we see that \\(R\_a(N)\\) is the coefficient of \\(z^N\\) in the Taylor expansion of \\(f\_{a,N}(z)\\) around \\(z=0\\). Thus, the Cauchy integral formula gives
\\[R\_a(N)=\frac1{2\pi i}\oint\_\gamma\frac{f\_{a,N}(z)}{z^{N+1}}\,dz,\\]
The lemma now follows by letting \\(\gamma\colon[0,1]\to\mathbb C\\) be the loop \\(\gamma(x):=e(x)\\), where we recall here that \\(e(x)=\exp(2\pi ix)\\). \\(\blacksquare\\)

We are now in a position to discuss the circle method. The idea is to estimate the integral
\\[\int\_{\mathbb R/\mathbb Z}f\_{a,N}(e(x))e(-Nx)\,dx\\]
directly. In short, the exponential sum \\(f\_{a,N}(e(x))\\) is expected to exhibit large cancellation for generic \\(x\\).
<!-- To be precise, we expect the absolute value to be small when \\(x\\) is far away from a rational. -->

To be precise, it will turn out to be the case that our main term arises from \\(x\\) being close to the rational \\(0\\), and we will be able to throw everything else in the integral into an error term. Thus, the values \\(x\\) close to \\(0\\) is called the "major arc," and everything else is called a "minor arc." Let's be explicit about these arcs.

> <span class="statement-label" id="def-arcs" data-env="Definition">Definition.</span>
Fix a real parameter \\(\varepsilon\in(0,1/2A)\\). Then the *major arc* \\(\mathfrak M\_{\varepsilon}\\) is the interval \\(\left[-\varepsilon,\varepsilon\right]\\). The *minor arc* \\(\mathfrak m\_{\varepsilon}\\) is the complement \\([-1/2,1/2]\setminus\mathfrak M\_{\varepsilon}\\).

The Minor Arc
-

Because it is a little easier, we start by estimating the minor arcs. The following rigorizes the idea that \\(f\_N\\) exhibits cancellation away from rationals.

> <span class="statement-label" id="lem-weyl-ineq" data-author="Weyl's inequality" data-env="Lemma">Lemma.</span>
For \\(x\in\mathbb R\\),
\\[f\_N(e(x))\lesssim\min\\left\\{N,\frac1{\lVert x\rVert}\right\\}.\\]

*Proof.*
The left bound by \\(N\\) holds by expanding \\(f\_N(e(x))\\) as a geometric sum, so it only remains to show the right bound. By periodicity, we may assume \\(x\in[-1/2,1/2]\\), and by symmetry, we may assume \\(x\in[0,1/2]\\); then we want to show \\(f\_N(e(x))\lesssim\lVert x\rVert^{-1}\\). Note
\\[f\_N(e(x))=\frac{1-e(2Nx)}{1-e(x)}.\\]
The numerator has absolute value at most \\(2\\), and \\(\left\|1-e(x)\right\|=2\left\|\sin\pi x\right\|\\), so \\(\left\|f\_N(e(x))\right\|\le\left\|\sin\pi x\right\|^{-1}\\). The lemma thus follows from the estimate \\(\left\|\sin\pi x\right\|\ge2\left\|x\right\|\\), which one can see (for example) by the concavity of \\(\left\|\sin\pi x\right\|\\). \\(\blacksquare\\)

> <span class="statement-label" id="rem-weird-ineq" data-env="Remark">Remark.</span>
We will use the following estimate twice, so we give it here: for \\(s\ge3\\), we claim
\\[\int\_{[-\varepsilon,\varepsilon]}\min\left\\{N,\frac1{\left\|t\right\|}\right\\}^{s-1}\,dt\stackrel?\lesssim\_\varepsilon N^{s-2}.\\]
For \\(\left\|t\right\|\le1/N\\), the minimum yields \\(N\\), so the integral is \\(\lesssim N^{s-2}\\). For \\(\left\|t\right\|\ge1/N\\), the minimum yields \\(1/\left\|t\right\|\\), so the integral is \\(\lesssim N^{s-2}\\). Combining the two bounds completes the proof. While we're here, we note that we can even bound the integral when \\(s=2\\) as \\(\lesssim\_\varepsilon\log N\\), due to the integral over \\(1/\left\|t\right\|\\).

Recall we set \\(A=\operatorname{lcm}(a\_1,\ldots,a\_s)\\). <a class="statement-ref" href="#lem-weyl-ineq">Lemma</a> basically implies that the factors of \\(f\_{a,N}(e(x))\\) should exhibit cancellation when \\(a\_kx\\) is far from an integer for each \\(k\\). We thus divide our minor arc estimates into two regimes depending on if \\(Ax\\) is close to an integer or not.

> <span class="statement-label" id="def-minor-arcs" data-env="Definition">Definition.</span>
Fix a real parameter \\(\varepsilon\in(0,1/2A)\\). For \\(b\in\mathbb Z/A\mathbb Z\\), define
\\[\mathfrak m\_{b,\varepsilon}:=\left(\frac bA+\mathfrak M\_{\varepsilon}\right)\cap[-1/2,1/2].\\]
For example, \\(\mathfrak m\_{0,\varepsilon}=\mathfrak M\_\varepsilon\\). Define \\(\mathfrak m'\_{\varepsilon}\\) to be the complement \\(\mathfrak m\setminus\bigcup\_b\mathfrak m\_{b,\varepsilon}\\).

> <span class="statement-label" id="lem-long-minor-arc" data-env="Lemma">Lemma.</span>
For a positive integer sequence \\((a\_1,\ldots,a\_s)\\),
\\[\int\_{\mathfrak m\_\varepsilon'}f\_{a,N}(e(x))e(-Nx)\,dx\lesssim\_{a,\varepsilon}1.\\]

*Proof.*
The length of \\(\mathfrak m\_{\varepsilon}'\\) is less than one, so it is enough to show that \\(f\_{a,N}(e(x))\lesssim\_{a,\varepsilon}1\\) for \\(x\in\mathfrak m\_{\varepsilon}'\\). By taking a product, it is enough to show that \\(f\_N(e(a\_kx))\lesssim\_{a,\varepsilon}1\\) for each \\(k\\) and \\(x\in\mathfrak m\_{\varepsilon}'\\). By <a class="statement-ref" href="#lem-weyl-ineq">Lemma</a>, it is enough to show that
\\[\lVert a\_kx\rVert\stackrel?\ge a\_k\varepsilon\\]
for each \\(k\\) and \\(x\in\mathfrak m\_{\varepsilon}'\\). Well, we proceed by contraposition: suppose that we have an integer \\(b\\) for which \\(\left\|a\_kx-b\right\| < a\_k\varepsilon\\). Then \\(x\in\mathfrak m\_{bA/a\_k,\varepsilon}\\), so \\(x\notin\mathfrak m\_\varepsilon'\\). \\(\blacksquare\\)

> <span class="statement-label" id="lem-short-minor-arc" data-env="Lemma">Lemma.</span>
Suppose \\(s\ge3\\). For a positive integer sequence \\((a\_1,\ldots,a\_s)\\) such that \\(\gcd(a\_1,\ldots,a\_s)=1\\) and nonzero \\(b\in\mathbb Z/A\mathbb Z\\),
\\[\int\_{\mathfrak m\_{b,\varepsilon}}f\_{a,N}(e(x))e(-Nx)\,dx\lesssim\_{a,\varepsilon} N^{s-2}.\\]

*Proof.*
We are going to bound the integral over \\(\left\|f\_{a,N}(e(x))\right\|\\) using <a class="statement-ref" href="#lem-weyl-ineq">Lemma</a>. Let's start by bounding the individual \\(f\_{N}(e(a\_kx))\\)s. There are two cases.
- If \\(a\_kb\\) is equivalent to some nonzero residue \\(r\pmod A\\), then \\(a\_kx\pmod{\mathbb Z}\\) is a distance of at most \\(a\_k\varepsilon\\) from \\(r/A\\), so \\(\lVert a\_kx\rVert\gtrsim\_{a,\varepsilon}1\\). Thus, by <a class="statement-ref" href="#lem-weyl-ineq">Lemma</a>, \\(f\_N(e(a\_kx))\lesssim\_{a,\varepsilon}1\\).
- Suppose \\(a\_kb\equiv0\pmod A\\). Then set \\(t:=x-b/A\\), and now <a class="statement-ref" href="#lem-weyl-ineq">Lemma</a> grants \\(f\_N(e(a\_kx))\\) admits the bound
\\[f\_N(e(a\_kt))\lesssim\min\left\\{N,\frac1{\lVert t\rVert}\right\\}.\\]

Quickly, observe that the first case must occur for at least one \\(k\\): indeed, if \\(a\_kb\equiv0\\) for all \\(k\\), then \\(b\equiv0\\) by taking linear combinations as in <a class="statement-ref" href="#rem-cor">Example</a>. Thus, the second case occurs at most \\(s-1\\) times, and we conclude
\\[\int\_{\mathfrak m\_{b,\varepsilon}}f\_{a,N}(e(x))e(-Nx)\,dx\lesssim\_{a,\varepsilon}\int\_{[-\varepsilon,\varepsilon]}\min\left\\{N,\frac1{\left\|t\right\|}\right\\}^{s-1}\,dt.\\]
We are now done by <a class="statement-ref" href="#rem-weird-ineq">Remark</a>. \\(\blacksquare\\)

<!-- The idea is to find an index \\(k\\) where some \\(f\_N(e(a\_kx))\\) is small. Because the length of \\(\mathfrak m\_{b,\varepsilon}\\) is \\(\lesssim N^{-1+\varepsilon}\\), it is enough to show
\\[\max\_{x\in\mathfrak m\_{b,\varepsilon}}\left\|f\_{a,N}(e(x))\right\|\stackrel?\lesssim\_a N^{s-1}.\\]
Note that \\(f\_N(e(x))=1+e(x)+\cdots+e((N-1)x)\\), so we always have the "trivial" estimate \\(\left\|f\_N(e(x))\right\|\le N\\). Thus, by taking a product, it is enough to show that
\\[\min\_k\max\_{x\in\mathfrak m\_{b,\varepsilon}}\left\|f\_{N}(e(a\_kx))\right\|\stackrel?\lesssim\_a1.\\]
By <a class="statement-ref" href="#lem-weyl-ineq">Lemma</a>, it is enough to show that
\\[\max\_k\min\_{x\in\mathfrak m\_{b,\varepsilon}}\lVert a\_kx\rVert\stackrel?\gtrsim\_a1.\\]
The main point is that we can find \\(k\\) for which \\(a\_kb\not\equiv0\pmod A\\); indeed, if \\(a\_kb\equiv0\\) for all \\(k\\), then \\(b\equiv0\\) by taking linear combinations as in <a class="statement-ref" href="#rem-cor">Example</a>. \\[\int\_{\mathfrak m\_\varepsilon}f\_{a,N}(e(x))e(-Nx)\,dx\lesssim\_{a,\varepsilon} N^{s-2}.\\]

*Proof.*

The Major Arc
-

We now turn to the task of estimating the major arc. The idea is to pass from \\(f\_{a,N}\\) to a more controlled function.

> <span class="statement-label" id="lem-major-estimate" data-env="Lemma">Lemma.</span>
For \\(x\in[-1/2,1/2]\\),
\\[f\_N(e(x))=\frac{e(2Nx)-1}{2\pi ix}+O(1).\\]
At \\(x=0\\), the right-hand side is understood to be defined by continuity.

*Proof.*
The difference between the two functions is
\\[(e(2Nx)-1)\left(\frac1{e(x)-1}-\frac1{2\pi ix}\right).\\]
We claim that the right-hand factor can be extended to a holomorphic function on the unit open disk around \\(0\\), which will complete the proof. Well, the only possible pole is at \\(z=0\\), where it is at worst simple. Thus, it is enough to show that the residue vanishes: the residue of \\((e(x)-1)^{-1}-(2\pi ix)^{-1}\\) at zero is
\\[\lim\_{x\to0}\left(\frac{x}{e(x)-1}-\frac1{2\pi i}\right).\\]
This limit vanishes. \\(\blacksquare\\)

> <span class="statement-label" id="prop-major-arc" data-env="Proposition">Proposition.</span>
Suppose \\(s\ge3\\). Fix a positive integer sequence \\((a\_1,\ldots,a\_s)\\). Then there is a constant \\(c\_a\\) satisfying the following: for a positive integer \\(N\\) and real parameter \\(\varepsilon\in(0,1/2A)\\),
\\[\int\_{\mathfrak M\_\varepsilon}f\_{a,N}(e(x))e(-Nx)\,dx=c\_aN^{s-1}+O\_{a,\varepsilon}\left(N^{s-2}\right).\\]

*Proof.*
For brevity, let the desired integral be \\(I\\). Recall \\(f\_{a,N}(z)=\prod\_kf\_N(z^{a\_k})\\), so <a class="statement-ref" href="#lem-major-estimate">Lemma</a> implies \\(f\_{a,N}(e(x))\\) is
\\[\prod\_{k=1}^s\left(\frac{e(2a\_kNx)-1}{2\pi ia\_kx}+O(1)\right)=\prod\_{k=1}^s\frac{e(2a\_kNx)-1}{2\pi ia\_kx}+O\_a\left(\min\\{N,1/\left\|x\right\|\\}^{s-1}\right).\\]
Here, we have used <a class="statement-ref" href="#lem-weyl-ineq">Lemma</a> to collect the error term. Integrating yields
\\[I=\frac1{a\_1\cdots a\_s}\int\_{\mathfrak M\_\varepsilon}e(-Nx)\prod\_{k=1}^s\frac{e(2a\_kNx)-1}{2\pi ix}\,dx+O\_{a,\varepsilon}\left(N^{s-2}\right).\\]
(The error term comes from <a class="statement-ref" href="#rem-weird-ineq">Remark</a>.) For convenience, let's extend the integral from \\(\mathfrak M\_\varepsilon\\) to \\(\mathbb R\\). Indeed, the integrand is \\(\lesssim\left\|x\right\|^{-s}\\), which has \\(\int\_{\varepsilon}^\infty x^{-s}\,dx\lesssim\_\varepsilon1\\). Thus,
\\[I=\frac1{a\_1\cdots a\_s}\int\_{\mathbb R}e(-Nx)\prod\_{k=1}^s\frac{e(2a\_kNx)-1}{2\pi ix}\,dx+O\_{a,\varepsilon}\left(N^{s-2}\right).\\]
To remove the dependence of the integral on \\(N\\), we substitute \\(x\mapsto x/N\\), which gives
\\[I=\frac{N^{s-1}}{a\_1\cdots a\_s}\int\_{\mathbb R}e(-x)\prod\_{k=1}^s\frac{e(2a\_kx)-1}{2\pi ix}\,dx+O\_{a,\varepsilon}\left(N^{s-2}\right),\\]
as desired. \\(\blacksquare\\)

It remains to compute the constant \\(c\_a\\), which the proof of <a class="statement-ref" href="#prop-major-arc">Proposition</a> reveals to be
\\[c\_a=\frac1{a\_1\cdots a\_s}\int\_{\mathbb R}e(-x)\prod\_{k=1}^s\frac{e(2a\_kx)-1}{2\pi ix}\,dx.\\]
The calculation of this integral is a little tricky, so we pass it off to a lemma.

> <span class="statement-label" id="lem-major-integral" data-env="Lemma">Lemma.</span>
Fix a positive integer sequence \\((a\_1,\ldots,a\_s)\\). For \\(s\ge2\\),
\\[\int\_{\mathbb R}e(-x)\prod\_{k=1}^s\frac{e(2a\_kx)-1}{2\pi ix}\,dx=\frac1{(s-1)!}.\\]

*Proof.*
Let the desired integral be \\(I\\). This is a fairly standard contour integral; for example, we will use the same tricks that one uses to compute \\(\int\_{\mathbb R}\frac{\sin x}x\,dx\\). Indeed, we can basically reduce to that integral after fully expanding the product. Of course, such an expansion is not entirely legal because the functions \\(e(bz)/z^s\\) have a pole at \\(z=0\\). Thus, we adjust the contour to avoid \\(z=0\\).

Fix some large \\(R>1\\). Let \\(\gamma\_0(R)\\) be the contour starting at \\(-R\\), following a straight line until \\(-1\\), following a semicircle in the upper-half plane until \\(1\\), and lastly continuing a straight line until \\(R\\). Because the integrand is holomorphic, we see
\\[I=\lim\_{R\to\infty}\int\_{\gamma\_0(R)}e(-z)\prod\_{k=1}^s\frac{e(2a\_kz)-1}{2\pi iz}\,dz.\\]
We are now allowed to fully expand the product. Then we see that we are interested in integrals over functions which look like \\(e(bz)/z^s\\). Accordingly, we claim that
\\[\lim\_{R\to\infty}\int\_{\gamma\_0(R)}\frac{e(bz)}{(2\pi iz)^s}\,dz\stackrel?=\begin{cases}0 & \text{if }b\ge0, \\\\-b^{s-1}/(s-1)! & \text{if }b<0.\end{cases}\\]
The lemma then follows by a full expansion of the product in \\(I\\). In particular, the only term in the expansion which contributes is \\(\int e(-z)(-1)^s/(2\pi iz)^s\,dz\\).

It remains to show the claim. We have two cases.
- Suppose \\(b\ge0\\). Then \\(\left\|e(bz)\right\|=\exp(-2\pi b\operatorname{Im}z)\\), which is bounded when \\(\operatorname{Im}z\\) is lower-bounded. Accordingly, define \\(\gamma\_+(R)\\) to be the counter-clockwise semicircle starting at \\(R\\) and ending at \\(-R\\), so the integral over \\(\gamma\_+(R)\\) is \\(o(1)\\). (For example, one can use \\(s\ge2\\) here.) We conclude that the answer is
\\[\lim\_{R\to\infty}\int\_{\gamma\_0(R)\cdot\gamma\_+(R)}\frac{e(bz)}{(2\pi iz)^s}\,dz.\\]
The contour encloses no poles, so this integral vanishes by the Cauchy integral formula.
- Suppose \\(b<0\\). By a symmetric argument to the previous point, we find that the answer is
\\[\lim\_{R\to\infty}\int\_{\gamma\_0(R)\cdot\gamma\_-(R)}\frac{e(bz)}{(2\pi iz)^s}\,dz,\\]
where \\(\gamma\_-(R)\\) is the clockwise semicircle starting at \\(R\\) and ending at \\(-R\\). This contour encloses a single pole around \\(z=0\\). The Cauchy integral formula (or a power series expansion of \\(e(bz)\\)) reveals that this integral equals \\(-b^{s-1}/(s-1)!\\), where the \\(-\\) arises for orientation reasons. \\(\blacksquare\\)

> <span class="statement-label" id="rem-sing-int" data-env="Remark">Remark.</span>
Difficult integrals like this one occur frequently in applications of the circle method. They are known as "singular integrals."

> <span class="statement-label" id="prop-major-arc-again" data-env="Proposition">Proposition.</span>
Suppose \\(s\ge3\\). Fix a positive integer sequence \\((a\_1,\ldots,a\_s)\\). For a positive integer \\(N\\) and real parameter \\(\varepsilon\in(0,1/2A)\\),
\\[\int\_{\mathfrak M\_\varepsilon}f\_{a,N}(e(x))e(-Nx)\,dx=\frac{N^{s-1}}{(s-1)!a\_1\cdots a\_s}+O\_{a,\varepsilon}\left(N^{s-2}\right).\\]

*Proof.*
Combine (the proof of) <a class="statement-ref" href="#prop-major-arc">Proposition</a> with <a class="statement-ref" href="#lem-major-integral">Lemma</a>. \\(\blacksquare\\)

> <span class="statement-label" id="rem-major-2" data-env="Remark">Remark.</span>
Once again, not all is lost at \\(s=2\\): the proof of <a class="statement-ref" href="#prop-major-arc">Proposition</a> gives an error of \\(O\_{a,\varepsilon}(\log N)\\); see <a class="statement-ref" href="#rem-weird-ineq">Remark</a>.

Completion of the Proof
-

Combining the estimates on the major and minor arcs produces the theorem.

> <span class="statement-label" id="thm-linear-circle" data-env="Theorem">Theorem.</span>
Let \\((a\_1,\ldots,a\_s)\\) be a sequence of positive integers for which \\(\gcd(a\_1,\ldots,a\_s)=1\\). Suppose \\(s\ge3\\). Then for positive integers \\(N\\), we have
\\[R\_a(N)=\frac{N^{s-1}}{(s-1)!a\_1\cdots a\_s}+O\_a\left(N^{s-2}\right).\\]

*Proof.*
By <a class="statement-ref" href="#lem-truncated-gen-func">Lemma</a>, we pass to estimating the integral
\\[\int\_{\mathbb R/\mathbb Z}f\_{a,N}(e(x))e(-Nx)\,dx.\\]
Summing <a class="statement-ref" href="#prop-minor-arc">Proposition</a> and <a class="statement-ref" href="#prop-major-arc-again">Proposition</a> (with any \\(\varepsilon\in(0,1/2A)\\)) gives the result. \\(\blacksquare\\)

At \\(s=2\\), using <a class="statement-ref" href="#rem-minor-2">Remark</a> and <a class="statement-ref" href="#rem-major-2">Remark</a> shows the same asymptotic with the worse error term \\(O\_a(\log N)\\).

Notably, this proves <a class="statement-ref" href="#thm-linear">Theorem</a> as soon as \\(s\ge2\\). Thus, we have a complete proof of <a class="statement-ref" href="#thm-linear">Theorem</a> once combined with <a class="statement-ref" href="#ex-one">Example</a>.

> <span class="statement-label" id="rem-circle-worse" data-env="Remark">Remark.</span>
The circle method performed worse than our earlier approach in <a class="statement-ref" href="#thm-linear-genfunc">Theorem</a>; for example, the error term at \\(s=2\\) discussed in <a class="statement-ref" href="#rem-circle-2">Remark</a> is worse. Nonetheless, the circle method is a powerful tool in other problems where one has less control of the poles of the relevant generating function. For example, one can use the circle method to count solutions to Diophantine equations such as
\\[x\_1^2+\cdots+x\_s^2=N.\\]
